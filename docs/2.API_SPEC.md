# 인스타그램 클론 API 명세서 (API Specification)

## 1. 공통 규약 (Conventions)

### Base URL
`https://api.commerce-clone.com/v1`

### 인증 (Authentication)
모든 보호된 리소스 요청 시 HTTP Header에 JWT Access Token을 포함해야 합니다.
`Authorization: Bearer <Access_Token>`

### 공통 응답 포맷 (Common Response Format)
```json
{
  "success": true,
  "data": { ... },
  "error": null
}
```
*   **에러 응답**:
    ```json
    {
      "success": false,
      "data": null,
      "error": {
        "code": "USER_NOT_FOUND",
        "message": "사용자를 찾을 수 없습니다."
      }
    }
    ```

### 페이징 (Pagination)
대용량 데이터(피드, 댓글 등) 조회 시 성능과 데이터 정합성을 위해 **Cursor 기반 페이징**을 사용합니다.
*   `cursor`: 이전 페이지의 마지막 아이템 ID (또는 Timestamp)
*   `limit`: 한 번에 조회할 개수 (Default: 20)

## 2. 사용자 서비스 (User Service)

### 회원가입
*   **POST** `/users/signup`
*   **Body**:
    ```json
    {
      "email": "user@example.com",
      "password": "secure_password",
      "name": "홍길동",
      "username": "gildong_hong"
    }
    ```

### 로그인
*   **POST** `/users/login`
*   **Body**: `{"email": "...", "password": "..."}`
*   **Response**: `{"accessToken": "...", "refreshToken": "..."}`

### 사용자 프로필 조회
*   **GET** `/users/{username}`
*   **Response**:
    ```json
    {
      "id": 12345,
      "username": "gildong_hong",
      "name": "홍길동",
      "profileImageUrl": "https://cdn...",
      "bio": "안녕하세요",
      "followerCount": 150,
      "followingCount": 45
    }
    ```

### 팔로우 / 언팔로우
*   **POST** `/users/{userId}/follow`
*   **DELETE** `/users/{userId}/follow`

---

## 3. 게시물 서비스 (Post Service)

### 게시물 작성
*   **POST** `/posts`
*   **Content-Type**: `multipart/form-data`
*   **Body**:
    *   `media`: File (Image/Video)
    *   `caption`: "오늘 날씨 좋네요 #daily"
*   **Response**: `{"id": 98765, "status": "PROCESSING"}` (비동기 처리 시)

### 게시물 상세 조회
*   **GET** `/posts/{postId}`

### 특정 사용자의 게시물 목록 (Grid)
*   **GET** `/users/{userId}/posts`
*   **Query**: `?cursor=12345&limit=18`

---

## 4. 피드 서비스 (Feed Service)

### 뉴스 피드 조회 (Timeline)
*   **GET** `/feeds/timeline`
*   **Query**: `?cursor=987654321&limit=20`
*   **Description**: 내가 팔로우한 사람들의 게시물을 최신순으로 조회.
*   **Response**:
    ```json
    [
      {
        "postId": 1001,
        "author": { "username": "friend1", "profileUrl": "..." },
        "imageUrl": "...",
        "caption": "여행 중",
        "likeCount": 52,
        "createdAt": "2024-05-01T10:00:00Z"
      },
      ...
    ]
    ```

---

## 5. 활동 서비스 (Activity Service) - Interaction

### 좋아요 (Like)
*   **POST** `/posts/{postId}/likes`
*   **DELETE** `/posts/{postId}/likes`
*   **Note**: 멱등성(Idempotency) 보장을 위해 중복 호출 시에도 성공(200 OK) 처리하되, 실제 카운트는 1회만 반영.

### 댓글 작성
*   **POST** `/posts/{postId}/comments`
*   **Body**: `{"content": "멋져요!", "parentId": null}` (parentId는 대댓글일 경우 원댓글 ID)

### 댓글 목록 조회
*   **GET** `/posts/{postId}/comments`
*   **Query**: `?cursor=...&limit=20`

---

## 6. 알림 서비스 (Notification Service)

### 알림 목록 조회
*   **GET** `/notifications`
*   **Response**:
    ```json
    [
      {
        "id": 555,
        "type": "LIKE",
        "actor": { "username": "fan1" },
        "message": "회원님의 사진을 좋아합니다.",
        "targetPostId": 1001,
        "isRead": false
      }
    ]
    ```
