# 인스타그램 클론 서비스 기능 명세서 (Functional Specification)

## 1. 서비스 개요
본 문서는 대규모 사용자를 대상으로 하는 소셜 미디어 플랫폼의 핵심 기능 정의와 업무 흐름을 기술합니다. 사용자는 사진과 동영상을 공유하고, 다른 사용자와 소통하며 자신만의 피드를 구성할 수 있습니다.

## 2. 사용자 여정 (User Journey Map)

1.  **진입**: 사용자는 앱/웹에 접속하여 로그인을 하거나 회원가입을 완료합니다.
2.  **탐색 (Feed)**: 메인 화면에서 팔로우한 친구들의 소식을 확인하고(Home Feed), 새로운 트렌드를 발견합니다(Explore Feed).
3.  **생성 (Post)**: 자신의 일상을 사진/영상으로 기록하고 업로드합니다.
4.  **반응 (Interaction)**: 관심 있는 게시물에 좋아요를 누르거나 댓글을 남겨 소통합니다.
5.  **알림 (Notification)**: 나에 대한 반응(좋아요, 팔로우 등)을 실시간으로 확인합니다.

---

## 3. 상세 기능 명세

### 3.1. 회원 및 프로필 (User & Profile)

#### [F-01] 회원가입 및 인증
*   **흐름**: 이메일 또는 소셜 계정으로 가입 -> 이메일/SMS 인증 -> 닉네임 설정 -> 완료.
*   **정책**:
    *   닉네임(User Handle)은 고유해야 하며 변경 가능하다.
    *   비밀번호는 암호화되어 저장되며, 분실 시 이메일로 재설정 링크를 발송한다.

#### [F-02] 프로필 관리
*   **기능**: 프로필 사진, 이름, 소개글(Bio), 웹사이트 링크 편집.
*   **정책**: 프로필 사진은 원형으로 크롭되어 표시된다.

#### [F-03] 팔로우 시스템
*   **흐름**:
    *   사용자 A가 사용자 B를 '팔로우' -> B의 팔로워 카운트 증가, A의 팔로잉 카운트 증가.
    *   A의 홈 피드에 B의 게시물이 노출되기 시작함.
*   **유명인(Influencer) 처리 정책**:
    *   팔로워가 특정 수(예: 100만 명) 이상인 경우, 팔로우 요청 시 알림 발송은 최소화하거나 묶어서 처리한다.

---

### 3.2. 피드 시스템 (Feed System)

#### [F-04] 홈 피드 (Timeline)
*   **정의**: 내가 팔로우하는 사용자들의 게시물을 모아보는 공간.
*   **노출 로직**:
    1.  기본적으로 최신순(Chronological)으로 정렬한다.
    2.  (고도화 시) 사용자의 반응 이력을 분석하여 친밀도 높은 사용자의 게시물을 상단에 배치한다.
*   **UX 흐름**: 무한 스크롤(Infinite Scroll) 방식을 적용하며, 새로고침 시 최신 데이터를 불러온다.

#### [F-05] 탐색 피드 (Discovery)
*   **정의**: 팔로우하지 않았지만 내 취향에 맞을 것으로 추측되는 게시물 노출.
*   **로직**: '최근 좋아요한 게시물'과 유사한 해시태그를 가진 인기 게시물을 추천한다.

---

### 3.3. 게시물 작성 및 관리 (Content Management)

#### [F-06] 미디어 업로드
*   **기능**: 사진(최대 10장) 또는 동영상(최대 60초) 업로드.
*   **흐름**: 미디어 선택 -> (필터/편집) -> 문구 작성 -> 업로드 버튼 클릭.
*   **백그라운드 처리**:
    *   사용자가 '업로드'를 누르면 즉시 UI는 완료 상태로 전환되거나 진행률을 표시한다.
    *   서버 내부적으로 원본 저장, 리사이징(썸네일), 압축 과정을 비동기로 수행한다.
    *   처리가 완료되면 피드에 최종 노출된다.

#### [F-07] 게시물 메타데이터
*   **기능**: 본문 텍스트 작성, 해시태그(#), 사용자 태그(@).
*   **해시태그 처리**: 본문 내 '#' 문자를 파싱하여 검색 인덱스에 등록한다.

---

### 3.4. 소셜 인터랙션 (Interaction)

#### [F-08] 좋아요 (Like)
*   **기능**: 하트 아이콘 클릭 시 좋아요 활성화/비활성화.
*   **동시성 정책**:
    *   사용자는 즉각적인 반응(UI 업데이트)을 보아야 한다.
    *   실제 카운트 집계는 서버 부하 상황에 따라 수 초의 지연이 발생할 수 있음을 허용한다(Eventual Consistency).

#### [F-09] 댓글 (Comment)
*   **기능**: 게시물에 텍스트 댓글 작성. 대댓글(Nested Comment) 지원.
*   **정책**: 댓글 수정은 불가능하며 삭제만 가능하다(또는 수정 기록 남김).

---

### 3.5. 검색 및 알림

#### [F-10] 검색
*   **기능**: 사용자 ID, 이름, 해시태그 검색.
*   **흐름**: 검색어 입력 시 실시간 자동완성 제안 -> 결과 클릭 시 해당 프로필 또는 해시태그 모음 페이지로 이동.

#### [F-11] 활동 알림
*   **범위**: 내 게시물에 좋아요/댓글 발생 시, 누군가 나를 팔로우했을 때.
*   **정책**: 동일한 게시물에 대한 반복적인 좋아요 알림은 "A님 외 100명이 좋아합니다" 형태로 축약하여 발송한다.

## 4. 데이터 및 제약 정책 (Business Rules)

1.  **콘텐츠 제한**:
    *   이미지는 장당 10MB 이하, 동영상은 500MB 이하로 제한한다.
    *   성인물, 폭력적인 콘텐츠는 AI 필터링 및 신고 시스템을 통해 블라인드 처리한다.
2.  **API 속도 제한 (Rate Limiting)**:
    *   일반 사용자의 과도한 API 호출(예: 매크로를 이용한 팔로우/좋아요)은 일시적으로 차단된다.
    *   짧은 시간 내에 너무 많은 게시물 작성 시 계정이 잠길 수 있다.
